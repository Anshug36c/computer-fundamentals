Module 1

Data vs Information

Everything a computer does is about turning raw data into useful information. If you understand this one idea, the whole subject falls into place.

1.1 What is Data?

Data means raw, unorganised, unprocessed facts and figures that have little or no meaning by themselves. Data is the input to a computer.

  • Examples: 45, 78, 92, 67  ·  Rahul, 21, Kichha  ·  the letters typed on a keyboard, the pixels from a camera, the reading of a thermometer.
  • Data on its own does not tell you what it is about. Is 45 a temperature, a mark, an age or a price? You cannot say.
  • Data is factual, uninterpreted and often huge in quantity.

1.2 What is Information?

Information is data that has been processed, organised and given context so that it becomes meaningful and useful for decision making. Information is the output of a computer.

  • Example: the numbers 45, 78, 92, 67 become information when presented as "Rahul scored 78 out of 100 — Grade B, class average 70.5, position 3rd."
  • Information is processed, interpreted and decision-oriented.

Module 2

The Information Processing Cycle

Also called the IPO cycle (Input–Process–Output) or IPOS cycle. It describes how a computer converts data into information. Almost every diagram question in Unit 1 comes from here.

2.1 The stages

  1. Input — Data and instructions are fed in using input devices (keyboard, mouse, scanner, mic, sensor, touchscreen) and stored in memory. At this moment data has no meaning yet.
  2. Processing — The CPU (ALU + Control Unit) performs arithmetic and logical operations: calculating, comparing, sorting, searching, classifying, summarising, formatting. Raw data becomes information. This is the "brain" step.
  3. Output — The result is presented in a human-usable form through output devices: monitor (soft copy), printer (hard copy), speakers, projector. This is the information.
  4. Storage — Data and results are kept for future use in primary memory (RAM) or secondary storage (HDD, SSD, pen drive, cloud). Without storage, every task would have to start from zero.

Some books add a 5th stage: Communication / Distribution — sending the output over a network to another user or machine. Others list Control/Feedback as a stage, because the control unit supervises the whole cycle. Mentioning either shows deeper knowledge.

Teacher's note Input devices + output devices together are called peripherals. The processor is the CPU. Storage is memory. So the cycle = Peripherals → CPU → Peripherals, with memory alongside.

Module 3

Introduction to Computers — What is a Computer?

The definition, word origin, and the exact reason a computer is different from a calculator.

3.1 Definition (learn one long + one short)

Definition — full version A computer is an electronic, programmable device that accepts data and instructions as input, processes them automatically according to a stored set of instructions (a program), produces meaningful information as output, and stores the results for future use.
Definition — short version "A computer is an electronic device that takes input, processes it according to instructions, gives output and can store the data." (The word is derived from the Latin computare = "to calculate".)

3.2 Breaking the definition down — every keyword matters

WordWhy it matters
ElectronicIt runs on electricity and uses electronic circuits (transistors, ICs); it works with binary signals 0 and 1.
ProgrammableIt can follow a set of stored instructions. Change the program → the same machine does a completely different job. This is the stored-program concept of John von Neumann, and it is the single most important idea in computing.
Accepts data (input)It cannot think of anything by itself; the data must be supplied.
AutomaticOnce started, it works without human intervention (a "self-acting" machine).
Produces information (output)It converts raw data into a usable form.
StoresIt remembers data and instructions — unlike a calculator which forgets.

3.3 Computer vs Calculator vs Human

FeatureCalculatorComputer
MemoryMinimal / temporary (only last result)Large; primary + secondary storage
ProgrammableNo (fixed operations)Yes (any program can be run)
Automatic workingNeeds key presses for every stepRuns a whole program automatically
DevicesKeypad + display onlyKeyboard, mouse, printer, disk, network…
Logic & decisionsNoYes, via conditional instructions ("if… then…")

3.4 The five-part picture of any computer system

Hardware (input + CPU + output + storage) + Software (system + application) + Data + Users/People + Procedure/Connectivity. In one line: "A computer system = hardware + software working together on data for people."

Note the difference between the two words:

  • Computer = the machine (hardware).
  • Computer system = the complete working setup: hardware + software + data + users + procedures.
Common mistake Do not define a computer as "a machine that calculates fast". Speed is a property, not the definition. A calculator can also be fast. The stored program ability is the real definition of a computer.
Module 4

Characteristics of Computers

The classic 10 powers and the equally classic 5 limitations. You will be asked "explain any four characteristics" — so learn the bold keyword and one example for each.

4.1 The strengths

CharacteristicMeaningExample / figure to quote
1. SpeedWorks at incredibly high speed — millions of instructions per second.Modern CPUs do billions of operations per second (GHz). A task of 1000 calculations takes microseconds; supercomputers measure speed in FLOPS (floating point operations per second).
2. AccuracyGives 100% correct results if the input and program are correct.Errors are due to bad data (GIGO) or bad logic — never due to "carelessness".
3. Diligence (consistency)Performs the same task repeatedly with the same accuracy — no tiredness, no boredom, no lunch breaks.Processing 10 lakh bank transactions at 3 a.m. just as carefully as the first one.
4. VersatilityThe same machine does many different jobs — typing, music, design, science, gaming, accounting, teaching. (Its sister term: adaptability / flexibility.)One laptop can be a music studio in the morning and an accounting office in the evening — only the software changes.
5. Storage capacityStores enormous amounts of data permanently and retrieves it instantly.From kilobytes (KB) in the 1980s to terabytes & petabytes today; cloud storage adds practically unlimited space.
6. AutomatismOnce a program is started it does the whole job itself without human help.Overnight batch processing; automatic backup at 2 a.m.
7. ReliabilityResults are dependable and repeatable; modern chips run for years.Same input + same program = same output, always.
8. Cost-effectivenessWork that needs many clerks can be done by one machine, cheaper per unit of work (even though initial hardware cost is high).One payroll server replaces 20 accountants' manual work.
9. Logical decision-makingCan compare and take decisions like "if marks ≥ 33 then pass" using logical/branching instructions.Automatic fee calculation with discounts for the right category.
10. Power of remembering (retrieval)Keeps data safe and can find any record instantly among millions.Searching a customer by name in a database of one crore records in milliseconds.
Memory hook S-A-D-V-S-A-R-C-L-P → "Some Androids Don't Very Simply Accept Random Crazy Logical Problems". Or, more simply, remember the famous trio first: Speed · Accuracy · Diligence, then Storage, Versatility, Automation.

4.2 The limitations (no machine is perfect)

LimitationExplanation
No intelligence of its own (no "IQ")A computer cannot think, reason or take its own decisions. It only obeys the instructions written by a human. (AI is software imitating certain intelligent behaviours — the machine itself still follows instructions.)
No emotions, feelings or judgementIt cannot sense love, taste, beauty or ethics. It cannot judge "should we do this?" — only "can this be computed?".
GIGO — depends on inputWrong data or wrong program → wrong output. Its accuracy is only as good as its input.
Needs electricity and maintenanceNo power, no computer. It also needs a controlled, clean environment especially for large systems.
Cannot learn from experience by itselfIt never gets "better with practice"; it must be reprogrammed/retrained.
Zero common senseAsk it to "take a break" and it has no idea — instructions must be literal and exact.
Typical exam framing "Computer is a dumb machine with a great memory." Explain in 4 lines: it has immense speed/accuracy/storage but no IQ, no emotions and no decision-making of its own — it is "garbage in, garbage out" and depends fully on the program (a human creation).
Module 5

Evolution and History of Computers

The story runs in two tracks: before electronic computers (calculating devices → Babbage) and the five generations (vacuum tubes → transistors → ICs → microprocessors → AI).

5.1 Why computers were invented — a one-line story

Humans needed to count, calculate, store and communicate faster and more accurately than hands and brains allow. So they invented calculating aids first (abacus, mechanical calculators), then machines that could follow stored instructions (Babbage, Hollerith), and finally fully electronic machines (ENIAC onwards) — which got smaller, cheaper, faster and more reliable with every generation.

Basic Organization of a Digital Computer

This is the highest-value diagram in the whole syllabus. Learn to draw the block diagram from memory and to explain each block in two lines.

7.1 The five functional units — block diagram

7.2 What each unit does

a) Input Unit

  • Accepts data and instructions from the outside world.
  • Converts them into the computer's internal binary (machine-readable) form.
  • Passes them to the CPU / memory. Without input, the computer cannot do anything.
  • Devices: keyboard, mouse, trackball, joystick, scanner, mic, webcam, touchscreen, light pen, digitizer, barcode/QR reader, OMR, OCR, MICR, biometric sensor, game controller.
  • Two families: keyboard-based (typed entry) and point-and-click / direct-entry (mouse, scanner, mic, sensor).

b) CPU — Central Processing Unit ("the brain")

Where all processing happens. It has three parts:

PartFunctionDetails
ALU — Arithmetic Logic UnitDoes the actual work on dataArithmetic: + − × ÷. Logical: comparisons (>, <, =, ≠) and Boolean operations (AND, OR, NOT). Produces the result, which is stored in a register — usually the Accumulator (ACC). It also sets flags (zero, carry, sign, overflow).
CU — Control UnitDirects and coordinates — it does not process dataFetches instructions from memory, decodes them, tells the ALU what operation to do, tells memory when to read/write, tells input/output devices when to act, and keeps everything in step with the system clock. It is the traffic police of the computer.
RegistersExtremely small, extremely fast storage inside the CPUPC (program counter — address of next instruction) · IR (instruction register — current instruction) · MAR (memory address register) · MDR (memory data register) · ACC (accumulator) · general-purpose registers. Size measured in bits (32-bit / 64-bit).
Memory hook ALU = All Logic Understanding (does the sums) · CU = Chief Umpire (gives the orders). A CPU is also called the computer's brain or processor; the chip itself is the microprocessor.

c) Memory Unit (storage)

  • Holds data, instructions and results. Memory is a giant array of numbered boxes ("cells"), each with a unique address.
  • Primary memory — directly accessed by the CPU, fast, small, costlier: RAM (volatile, read/write, working memory), ROM (non-volatile, read-only, stores start-up instructions), Cache (fastest, keeps frequently used data).
  • Secondary memory — permanent, huge, cheap, slower: HDD, SSD, optical discs, pen drive, memory card, cloud.
  • Why two levels? Because extremely fast memory is extremely expensive and small. This compromise is called the memory hierarchy.

d) Output Unit

  • Converts the machine's binary results back into human-readable form.
  • Soft copy (on screen — temporary): monitor/LCD/LED/OLED, projector, speakers, headphones.
  • Hard copy (physical — permanent): printers — impact (dot-matrix, daisy wheel, line printer) and non-impact (inkjet, laser, thermal, 3D printer); plotter for engineering drawings.

7.4 How an instruction actually runs — the instruction cycle

Every program is just a list of instructions like "ADD 5" or "LOAD A". The CPU repeats this cycle billions of times per second:

  1. FETCH — The Control Unit reads the next instruction from memory. Address comes from the PC (program counter), which is then incremented to point to the next instruction.
  2. DECODE — The instruction is placed in the IR and the CU figures out what it means: what operation, which data (operand).
  3. EXECUTE — The ALU performs the operation, or data is moved between registers/memory, or the CU signals a device to act.
  4. STORE / WRITE-BACK — The result is stored in a register or in memory, and status flags are updated. Then the cycle repeats for the next instruction.
Exam tip This cycle is also called the fetch–decode–execute cycle or machine cycle. Mentioning that the same memory holds both data and instructions (the stored-program concept) is what distinguishes the von Neumann architecture from the Harvard architecture (separate instruction and data memories — used in many microcontrollers and DSPs).

8.1 What is a number system?

A number system is a set of symbols (digits) and rules for representing numbers. Every number system has a base or radix (r), which tells you:

  • How many different symbols (digits) exist → exactly r digits, from 0 to r−1.
  • The place value (weight) of each position → powers of r: …, r³, r², r¹, r⁰ . r⁻¹, r⁻², …
  • When a carry is generated — after reaching r−1, the next count rolls over to 10.

Example in decimal (r = 10): 3472 means 3×10³ + 4×10² + 7×10¹ + 2×10⁰ = 3000 + 400 + 70 + 2.

Each digit has a face value (the digit itself) and a place value (digit × weight of its position). The radix point separates the integer part from the fraction part.

How signs are stored
  • Sign-magnitude: MSB = sign (0 positive, 1 negative), rest = magnitude. Range for 8 bits: −127 to +127. Has two zeros (+0, −0).
  • 1's complement: negative numbers made by inversion. Range −127 to +127; still two zeros.
  • 2's complement (used everywhere today): range −128 to +127 for 8 bits, only one zero, and addition/subtraction work directly. Range formula: −2n−1 to +2n−1 − 1.
  • Overflow: if the true sum lies outside that range, the sign flips wrongly. E.g. 127 + 1 in 8 bits = 01111111 + 1 = 10000000 = −128 (overflow). Detect it by comparing the carry into the MSB with the carry out of the MSB.

8.17 Why do computers use the binary system? (a favourite 5-mark theory question)

  1. Two-state devices are simple and reliable. A transistor/switch is either OFF or ON; a magnetic spot is either magnetised or not; a voltage is either high or low. Building circuits with ten distinguishable voltage levels would be expensive and error-prone — noise would flip digits. Two levels give a huge noise margin.
  2. Boolean logic fits perfectly. 0 = False, 1 = True, and logic gates (AND, OR, NOT) implement arithmetic with simple circuits.
  3. Less hardware, less cost, less error. Only two symbols to handle means simpler, cheaper, faster circuits and higher reliability.
  4. Easy to store and transmit. Storage media and signals naturally hold two states (magnetised/not, pit/no pit, high/low voltage).
  5. Arithmetic is simple. Only 4 addition rules and 4 multiplication rules in binary, and subtraction is done by complement addition (no need for a separate subtractor).

Downside: long strings (a 4-digit decimal like 1000 needs 10 bits) — which is exactly why octal and hex exist as human-friendly shorthands.

9.2 How different kinds of data are represented inside the computer

  • Numbers — binary (with 2's complement for negatives, and floating-point for fractions/in scientific work).
  • Text/characters — codes: ASCII (8-bit), Unicode/UTF-8 (variable), BCD for decimal displays.
  • Images — a grid of pixels, each pixel stored as a number. In bitmap images, colour = 24-bit (8 bits each for Red, Green, Blue, i.e. 16.7 million colours); higher resolution and colour depth = bigger file. Vector images store shapes and formulas instead (scalable).
  • Audio — the sound wave is sampled thousands of times a second (sampling rate, e.g. 44.1 kHz) and each sample stored as a number; higher rate and bit depth = better quality, bigger file (MP3 compresses by discarding what the ear cannot hear).
  • Video — a sequence of images (frames) played at 24–60 fps plus audio; compressed with codecs (MP4/H.264).
  • Every single item is ultimately a string of 0s and 1s — a 1 MB photo is about 8 million bits.

9.5 Bits, bytes and the word length

  • Bit = a single binary digit. It is the atom of information (coined from "binary digit").
  • Byte = 8 bits; enough for one ASCII character. A byte can store 2⁸ = 256 different values (0–255).
  • Word length = the number of bits the CPU handles in one operation (8/16/32/64). Bigger word length = faster and more accurate machine; today's PCs are 64-bit.
  • Address = a unique number labelling each memory cell; the CPU says "read address 42" rather than "read the third box after the blue one".
  • How many bit patterns in n bits? 2ⁿ. How many distinct values in n bits? 2ⁿ, ranging 0 to 2ⁿ − 1 (unsigned).

Part A — Theory (short & long answer)

Q1. Define data and information with one example each, and state the relationship between them.
Data = raw, unorganised facts and figures with no meaning by themselves, e.g. the numbers 45, 78, 92. Information = processed, organised data that is meaningful and useful for decision making, e.g. "the class average is 70.5 and Rahul stood 3rd". Relationship: data is the input, processing converts it into information which is the output; information is often re-used as data for the next level of processing.
Q2. Explain the information processing cycle with a real-world example.
The cycle has four stages. Input: data and instructions are entered through input devices and stored. Processing: the CPU (ALU + CU) performs arithmetic/logical operations. Output: the result is presented as information (soft or hard copy). Storage: data and results are saved for future use. Example (ATM): card + PIN + amount (input) → verify PIN, check balance and debit (processing) → cash and receipt (output) → updated account record saved (storage). Some books add communication/feedback as a fifth stage.
Q3. Write any six characteristics of a computer.
1. Speed — billions of operations per second. 2. Accuracy — results are 100% correct if input and program are correct. 3. Diligence — works at the same accuracy for hours without fatigue. 4. Versatility — one machine performs many different jobs by changing software. 5. Storage — stores huge amounts of data permanently with instant retrieval. 6. Automation — once started, it works on its own. (Others: reliability, cost-effectiveness, logical decision-making, no boredom.)
Q4. "A computer is a dumb machine with a great memory." Justify.
A computer has no intelligence, no feelings, no common sense and no ability to take its own decisions — it can only obey the instructions given by a human (program). But it has enormous memory, speed and accuracy. So although it looks "clever", the cleverness is the programmer's; the machine is a fast, obedient, tireless but thoughtless servant. Hence "GIGO" — garbage in, garbage out. This is why we say a computer is a dumb machine with a great memory.
Q5. Distinguish between analog, digital and hybrid computers with examples.
Analog: works on continuous physical quantities such as voltage or pressure; very fast but less accurate; gives results as graphs/dials — speedometer, thermometer. Digital: works on discrete data (0s and 1s) by counting; very accurate, can store data and give exact numeric output — laptop, calculator. Hybrid: accepts analog data, converts it to digital, processes it digitally and can output analog signals — combines speed with accuracy — ECG machine, petrol pump, aircraft control system.
Q6. Classify computers on the basis of size, speed and cost.
Supercomputer: most powerful and costliest; petaFLOPS–exaFLOPS; used in weather forecasting, nuclear simulation, AI — PARAM Siddhi, Fugaku. Mainframe: very large, thousands of simultaneous users, high-volume transactions — IBM z Series used by banks and railways. Minicomputer/midrange: medium-sized multi-user machine for a department or college — PDP-11, IBM AS/400. Microcomputer: single-user personal computer — desktop, laptop, tablet, smartphone. Order of size/power/cost: Super > Mainframe > Mini > Micro.
Q7. Explain the basic organization of a digital computer with a block diagram.
Draw the diagram: input unit → CPU (ALU + Control Unit + registers) ↔ memory unit → output unit, connected by the system bus. Explain: Input unit accepts data/instructions and converts them to binary form. ALU performs arithmetic and logical operations. Control unit fetches, decodes and directs the execution of instructions, i.e. it controls and coordinates all units. Registers are very fast temporary storage inside the CPU (PC, IR, MAR, MDR, ACC). Memory unit stores data and instructions — primary (RAM, ROM, cache) and secondary (HDD, SSD, pen drive). Output unit converts results to human-readable form — monitor (soft copy), printer (hard copy). The three buses (data, address, control) carry information between them.
Q8. What is the difference between the ALU and the Control Unit?
ALU (Arithmetic Logic Unit) actually performs the data operations — arithmetic (+ − × ÷) and logical (comparison, AND, OR, NOT) — and stores the result in a register such as the accumulator; it also sets status flags. Control Unit does not process data at all; it fetches instructions from memory, decodes them and generates the control signals that tell the ALU, memory and I/O devices what to do and when, keeping everything synchronised with the clock. In short, the ALU is the worker; the CU is the supervisor.
Q9. What is the stored-program concept and who gave it?
The idea that both data and the sequence of instructions (program) are stored in the same main memory, so the machine can read instructions from memory one after another and execute them automatically without the programmer rewiring the hardware for each new job. It was described by John von Neumann in the 1945 "First Draft of a Report on the EDVAC". Nearly every computer today follows this von Neumann architecture. (In the alternative Harvard architecture, instructions and data have separate memories.)
Q10. Describe the five generations of computers in brief.
1st (1940–56): vacuum tubes; huge, hot, unreliable, costly; machine language; punched cards — ENIAC, UNIVAC-I. 2nd (1956–63): transistors; smaller, faster, reliable; FORTRAN, COBOL, assembly; batch processing — IBM 1401. 3rd (1964–71): integrated circuits; operating systems, time-sharing, minicomputers; keyboard/monitor — IBM System/360, PDP-8. 4th (1971+): microprocessors and VLSI; personal computers, GUI, networks, internet, laptops, smartphones — Intel 4004, IBM PC. 5th (present & future): artificial intelligence, parallel and quantum computing, machine learning and robotics — IBM Watson, self-driving cars, generative AI.
Q11. Who is called the father of the computer and why?
Charles Babbage (1791–1871). He designed the Difference Engine (1822) for mathematical tables and the Analytical Engine (1837), the first design of a general-purpose, programmable machine with all the parts of a modern computer: a "mill" (processing unit = CPU), a "store" (memory), input via punched cards, and a printer for output. Its design even included conditional branching. Because the whole logical architecture of the modern computer was conceived by him — though it could not be built with the technology of his time — he is called the Father of the Computer.
Q12. What is a computer? Give the full definition and explain each keyword.
"A computer is an electronic, programmable device that accepts data and instructions as input, processes them automatically according to a stored set of instructions, produces meaningful information as output and stores the results for future use." Electronic → runs on electricity using circuits and binary signals. Programmable → it follows stored instructions, so the same machine does any job by changing the program. Data/instructions → it cannot think; input must be supplied. Automatic → it works without step-by-step human help. Output/storage → it converts data into information and remembers it. (Word origin: Latin computare — to calculate.)
Q13. What are the main limitations of a computer?
1. No intelligence of its own — it cannot think or take independent decisions; it must be programmed. 2. No emotions, feelings or moral judgement. 3. GIGO — accuracy depends completely on input data and the program. 4. Needs electricity, maintenance and a suitable environment. 5. Cannot learn from experience by itself. 6. No common sense — instructions must be literal and exact. It follows the program blindly, even if the program is wrong.
Q14. Differentiate between primary and secondary memory.
Primary (main) memory is directly accessible to the CPU, is very fast and expensive, smaller in capacity; it includes RAM (volatile, read/write working memory), ROM (non-volatile, firmware) and cache. Secondary (auxiliary) memory is not directly accessed by the CPU, is slower and cheaper, much larger in capacity and permanent — HDD, SSD, optical discs, pen drives, memory cards, cloud storage. Data moves from secondary storage into primary memory when it is to be processed, and is saved back for permanence.

Q16. What is cache memory and why is it needed?
Cache is a small, very fast memory placed between the CPU and main memory (RAM) that holds recently and frequently used data and instructions. It is needed to bridge the speed gap — the CPU works in nanoseconds while RAM is much slower, so the CPU would sit idle waiting for data. Cache reduces that waiting time (its "hit rate" decides performance). Levels: L1 (smallest, inside the core, fastest), L2, L3 (larger, shared). It is expensive, which is why it is small, and it is volatile.
Q17. Explain the system bus and its three types.
A bus is a set of parallel electrical lines that carries information between the CPU, memory and I/O devices. Data bus: bidirectional; carries the actual data and instructions; its width (8/16/32/64 bits) decides how much is transferred at a time. Address bus: unidirectional from CPU to memory; carries the address of the location to be read/written; with n lines it can address 2ⁿ locations (32 lines → 2³² ≈ 4 GB). Control bus: carries control and timing signals such as read, write, interrupt, clock and reset, and thus synchronises all operations.
Q18. Describe the instruction cycle (machine cycle).
1. Fetch: the control unit reads the next instruction from the memory address held in the Program Counter; the PC is incremented. 2. Decode: the instruction goes into the Instruction Register and the CU works out what operation and which operands are involved. 3. Execute: the ALU performs the operation (or data is moved, or a device is signalled). 4. Store/write-back: the result is written to a register or memory and the status flags are updated. The cycle then repeats for the next instruction — billions of times per second, timed by the system clock.
Q19. What is a number system? Define base/radix.
A number system is a set of symbols (digits) together with rules for writing numbers using those symbols. The base or radix (r) is the total number of distinct symbols available; the digits are 0 to r−1 and the place values (weights) are the powers of r. E.g. in octal, r = 8, digits are 0–7, weights are …64, 8, 1; in hex, r = 16, digits 0–9 and A–F, weights …256, 16, 1.
Q20. Why does a computer use the binary number system?
Because (i) digital circuits are cheapest and most reliable with just two stable states — ON/OFF, high/low voltage (with ten levels, noise would cause errors); (ii) it maps exactly onto Boolean logic (0 = false, 1 = true), so logic gates can do arithmetic; (iii) arithmetic has only 4 addition and 4 multiplication rules, and subtraction is done by complement addition — so the hardware is simple, small, fast and cheap; (iv) storage media and signals naturally hold two states.
Q21. Why do we need octal and hexadecimal when the computer works in binary?
Purely for human convenience. Long binary strings are hard to read and error-prone. Since 2³ = 8 and 2⁴ = 16, one octal digit corresponds to exactly 3 bits and one hex digit to exactly 4 bits, so binary can be compressed and converted back without any calculation. Example: 110110101011 (12 bits) = DAB in hex. Hex is used for memory addresses, colour codes, MAC addresses and machine-level programming; octal for Unix file permissions (chmod 755).
Q22. What is the difference between positional and non-positional number systems?
In a positional system the value of a digit depends on its position — 47 and 74 are different; the digit is multiplied by the weight (power of the base) of its position. All modern systems (decimal, binary, octal, hex) are positional. In a non-positional system the symbol has a fixed value wherever it appears — Roman numerals (X = 10 in XI and XIX) and tally marks. Arithmetic is far easier in positional systems, which is why computers use them.
Q23. Explain the two methods of converting a decimal integer to binary. Which is faster?
Repeated division: divide by 2 repeatedly, note the remainders, and read them from bottom to top (the last remainder is the MSB). Power subtraction: write the powers of 2 (… 32, 16, 8, 4, 2, 1), put 1 where a power fits into the remaining value, subtract, and 0 elsewhere. Power subtraction is faster for small numbers and for mental calculations; repeated division always works, however large the number. Tip: verify the answer by expanding the binary back into a sum of weights.
Q24. What are the 1's complement and 2's complement of a binary number, and why is 2's complement used?
1's complement = invert every bit (0→1, 1→0). 2's complement = 1's complement + 1 (equivalently, copy bits from the right up to and including the first 1, then invert the rest). 2's complement is used because subtraction can then be done by addition (a − b = a + 2's complement of b, discarding the final carry), so one adder circuit does both jobs; it also has only one representation of zero and gives a clean signed range of −2n−1 to +2n−1−1.
Q25. What is BCD? How is 45 represented in BCD?
BCD (Binary Coded Decimal) represents each individual decimal digit separately in 4-bit binary (weights 8-4-2-1). For 45: 4 → 0100 and 5 → 0101, so (45)₁₀ = 0100 0101 in BCD. It is easy for decimal displays/calculators but wasteful, since 4 bits could hold 16 values and BCD uses only 0–9 (1010–1111 are invalid codes).
Q26. What is Unicode and how is it different from ASCII?
ASCII is a 7-bit code (extended to 8-bit) giving 128/256 codes — enough for English letters, digits and punctuation ('A' = 65, 'a' = 97, '0' = 48) but not for other scripts. Unicode is a universal character-encoding standard with more than a lakh code points covering all the world's writing systems, symbols and emoji; its UTF-8 form is backward-compatible with ASCII for the first 128 characters, which is why UTF-8 dominates the web.
Q27. What is a parity bit and what is it used for?
A parity bit is an extra bit appended to a group of bits for error detection during storage or transmission. In even parity the bit is chosen so that the total number of 1s becomes even; in odd parity, odd. On reception the parity is recalculated — a mismatch means an error occurred. Limitation: it can detect a single-bit error (and cannot correct it), and it fails if two bits flip at the same time.
Q28. What are the differences between hardware and software?
Hardware is the physical, touchable part (CPU, RAM, keyboard, monitor) — it wears out with use and is manufactured. Software is the set of programs/instructions (Windows, MS Word, browsers) — intangible, does not wear out but becomes obsolete, and is written by programmers. Neither can work alone: hardware without software is dead, software without hardware cannot run. Firmware sits between them — permanent software stored in ROM/BIOS. Software types: system software (OS, drivers, utilities, translators) and application software (general-purpose like Excel, and specific-purpose like payroll or railway reservation).
Q29. Write short notes: (a) ENIAC (b) von Neumann (c) UNIVAC-I (d) Intel 4004.
(a) ENIAC (1946, Eckert & Mauchly, Univ. of Pennsylvania): first large general-purpose electronic digital computer; ~18,000 vacuum tubes, ~30 tonnes, room-sized; programmed by rewiring plugboards. (b) John von Neumann: gave the stored-program concept (EDVAC report, 1945) in which data and instructions share the same memory — the basis of all modern computers. (c) UNIVAC-I (1951): the first commercial computer sold in the USA; famously predicted the 1952 presidential election. (d) Intel 4004 (1971): the first microprocessor — a complete 4-bit CPU on a single chip, which made the personal computer possible.
Q30. What is a supercomputer? Where is it used, and what does India have?
A supercomputer is the fastest and most powerful class of computer, with thousands of processors working in parallel, speed measured in peta/exaFLOPS, costing crores and requiring heavy cooling and power. Uses: weather and cyclone forecasting, climate modelling, nuclear and defence simulation, drug discovery and genome analysis, oil exploration, AI training, animation rendering. India: PARAM 8000 (1991) — the country's first indigenous supercomputer built by C-DAC under Dr. Vijay Bhatkar; today the PARAM series, PARAM Siddhi-AI and the National Supercomputing Mission's PARAM Rudra systems.
Q31. Explain the difference between a general-purpose and a special-purpose computer.
General-purpose: versatile — can be programmed to do any job (word processing, accounts, gaming, design) and can be used by many users for different tasks; a single machine supports many applications. Examples: desktop, laptop, server, tablet. Special-purpose (dedicated): designed and built for one specific task only, with the logic fixed inside; often smaller, cheaper and faster for that job. Examples: ATM, washing-machine controller, digital camera, microwave, car engine control unit, POS billing machine, MRI scanner, traffic-light controller.
Q32. What is the role of the system clock and how is computer speed measured?
The system clock is a crystal oscillator that generates a steady stream of pulses which synchronise every operation in the CPU — each pulse (or a fixed number of them) allows one micro-operation, so the clock is the heartbeat of the computer. Speed is measured as clock frequency in Hz/MHz/GHz (cycles per second), MIPS (million instructions per second) or FLOPS (floating-point operations per second) for scientific/supercomputers. Other factors affecting real speed: word length, cache size, number of cores, and memory/disk speed.

1's complement = 00110101; 2's complement = 00110101 + 1 = 00110110
Q46. Perform (10110)₂ − (1101)₂ using 2's complement.
Use 8 bits: 10110 = 00010110; 1101 = 00001101; its 2's complement = 11110011. Add: 00010110 + 11110011 = (1)00001001 → discard the carry → 00001001 = (9)₁₀ ✔ (22 − 13 = 9)
Q47. Add (1111)₂ + (1011)₂ and verify in decimal.
1111 + 1011 = 11010. Check: 15 + 11 = 26 = 11010₂ ✔
Q48. Multiply (101)₂ × (11)₂.
101 × 11 = 101 + 1010 = 1111 = 15 ✔ (5 × 3 = 15)
Q49. Add (47)₈ + (65)₈.
7+5 = 12 = 1×8+4 → write 4, carry 1; 4+6+1 = 11 = 1×8+3 → write 3, carry 1 → (134)₈. Check decimal: 39 + 53 = 92 = 134₈ ✔
Q50. Add (FF)₁₆ + (1)₁₆.
(100)₁₆ (= 255 + 1 = 256). Note the carry generates a new hex digit — this is exactly how a byte overflows into the next byte.
Q51. Write (950)₁₀ in BCD.
9 → 1001, 5 → 0101, 0 → 0000 → 1001 0101 0000
Q52. Find the Gray code of the binary number (1110)₂.
MSB copied = 1; then XOR adjacent bits: 1⊕1 = 0, 1⊕1 = 0, 1⊕0 = 1 → 1001 (Gray). Verify: converting 1001 back gives 1110, and only one bit changes between successive Gray values.
Q53. Convert (101.101)₂ to decimal.
4 + 0 + 1 + 0.5 + 0 + 0.125 = (5.625)₁₀
Q54. What is the range of numbers that can be stored in 8 bits in (a) unsigned (b) 2's complement signed form?
(a) 0 to 255 (2⁸ − 1). (b) −128 to +127 (formula: −2n−1 to 2n−1 − 1).
Q55. What is the largest number that can be represented in 10 bits?
2¹⁰ − 1 = 1023 (i.e. 1111111111₂)
Q56. How many bits are needed to represent 100 in binary?
100 = 1100100₂ → 7 bits (general rule: the number of bits = ⌊log₂ n⌋ + 1)
Q57. Give the ASCII decimal values and 7-bit binary of 'B', 'b' and '1'.
'B' = 66 = 1000010; 'b' = 98 = 1100010; '1' = 49 = 0110001. (Remember 'A' = 65, difference between upper and lower case = 32.)
Q58. Write the IP address 192.168.0.1 in binary.
192 = 11000000, 168 = 10101000, 0 = 00000000, 1 = 00000001 → 11000000.10101000.00000000.00000001 (each octet is 8 bits — hence an IPv4 address is 32 bits long).
Q59. Convert (12)₁₀ to binary and (12)₁₀ to hex.
(1100)₂ and (C)₁₆
Q60. Convert (1000)₁₀ to hex, and convert that hex answer back to decimal to verify.
1000 ÷ 16 = 62 r 8 → 62 ÷ 16 = 3 r 14(E) → 3 ÷ 16 = 0 r 3 → (3E8)₁₆. Verify: 3×256 + 14×16 + 8 = 768 + 224 + 8 = 1000 ✔
Q61. Convert (777)₈ to decimal. What is special about it?
7×64 + 7×8 + 7 = 448 + 56 + 7 = (511)₁₀ = 2⁹ − 1 — the largest 9-bit number, just as (777)₈ is the largest 3-digit octal number.
Q62. Which of these is the largest: (10011)₂, (23)₈, (13)₁₆, (19)₁₀?
A trick question — all four are equal to 19. (10011)₂ = 16+2+1 = 19; (23)₈ = 2×8+3 = 19; (13)₁₆ = 16+3 = 19; (19)₁₀ = 19. Moral: converting everything into one base is the safest way to compare numbers written in different bases.
How to score full marks in numerical questions Always (1) write the base as a subscript, (2) show the division/multiplication table, (3) draw an arrow showing the direction of reading, (4) verify by converting back, and (5) box the final answer with its base.
