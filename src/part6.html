9.2 How different kinds of data are represented inside the computer

  • Numbers — binary (with 2's complement for negatives, and floating-point for fractions/in scientific work).
  • Text/characters — codes: ASCII (8-bit), Unicode/UTF-8 (variable), BCD for decimal displays.
  • Images — a grid of pixels, each pixel stored as a number. In bitmap images, colour = 24-bit (8 bits each for Red, Green, Blue, i.e. 16.7 million colours); higher resolution and colour depth = bigger file. Vector images store shapes and formulas instead (scalable).
  • Audio — the sound wave is sampled thousands of times a second (sampling rate, e.g. 44.1 kHz) and each sample stored as a number; higher rate and bit depth = better quality, bigger file (MP3 compresses by discarding what the ear cannot hear).
  • Video — a sequence of images (frames) played at 24–60 fps plus audio; compressed with codecs (MP4/H.264).
  • Every single item is ultimately a string of 0s and 1s — a 1 MB photo is about 8 million bits.

9.4 Where number systems meet real life (great for viva "applications" questions)

IPv4 addresses

Written in decimal but stored as 4 bytes, e.g. 192.168.1.1 = 11000000.10101000.00000001.00000001.

IPv6 & MAC addresses

Written in hexadecimal — e.g. MAC 3C:5A:B4:1F:9E:22, IPv6 in 8 hex groups.

Colour codes in HTML/CSS

#FF0000 = red (FF, 00, 00 for R, G, B). Each pair is one byte of 0–255.

File permissions (Unix/Linux)

chmod 755 is octal — 7 = rwx for the owner, 5 = r-x for group and others.

Memory addresses & disassembly

Debuggers show addresses like 0x7FFE4A2C — hexadecimal, because it maps cleanly onto bits.

Storage sizes

Everything counted in powers of 2: 4 GB RAM = 4 × 2³⁰ bytes ≈ 43 crore bytes.

Digital clocks / time & angles

Base-60 (sexagesimal) residue: 60 seconds, 60 minutes, 360° = 60×6.

Bar codes, ISBN, Aadhaar

Check digits use modular arithmetic on the digits — a cousin of the parity idea.

9.5 Bits, bytes and the word length

  • Bit = a single binary digit. It is the atom of information (coined from "binary digit").
  • Byte = 8 bits; enough for one ASCII character. A byte can store 2⁸ = 256 different values (0–255).
  • Word length = the number of bits the CPU handles in one operation (8/16/32/64). Bigger word length = faster and more accurate machine; today's PCs are 64-bit.
  • Address = a unique number labelling each memory cell; the CPU says "read address 42" rather than "read the third box after the blue one".
  • How many bit patterns in n bits? 2ⁿ. How many distinct values in n bits? 2ⁿ, ranging 0 to 2ⁿ − 1 (unsigned).
Module 10

Quick Revision Sheet — the night before the exam

If you read only one page, read this one. Everything is compressed into lists you can memorise in 30 minutes.

Definitions in one line

Data — raw, unprocessed facts.
Information — processed, meaningful data used for decisions.
Computer — electronic, programmable device that accepts input, processes per stored instructions, gives output, stores results.
Number system — a set of digits and rules with a base r → digits 0…r−1.
Base/radix — number of symbols in the system.

The cycles

IPOS: Input → Processing → Output → Storage.
Machine cycle: Fetch → Decode → Execute → Store (billions of times per second).
Data processing → Information.

Generations (V-T-I-M-A)

1: Vacuum tubes (1940–56) — ENIAC, UNIVAC-I
2: Transistors (1956–63) — FORTRAN, COBOL
3: ICs (1964–71) — IBM System/360, OS, time-sharing
4: Microprocessors/VLSI (1971+) — PC, internet, GUI
5: AI/ULSI (present) — ML, robotics, quantum

Fathers & firsts

Babbage — Father of the computer.
Ada Lovelace — first programmer.
Von Neumann — stored-program concept.
Alan Turing — Turing machine, Turing test.
Hollerith — punched cards → IBM.
ENIAC — first general-purpose electronic digital computer (1946).
UNIVAC-I — first commercial computer.
Intel 4004 — first microprocessor (1971).

Number systems

Binary r=2 (0,1) · Octal r=8 (0–7) · Decimal r=10 (0–9) · Hex r=16 (0–9,A–F)
1 octal digit = 3 bits · 1 hex digit = 4 bits

Conversion methods

Dec → other: divide by base, read remainders bottom-up.
Fraction: multiply by base, read integer parts top-down.
Other → Dec: weights (powers of base).
Binary ↔ Octal: groups of 3.
Binary ↔ Hex: groups of 4.
Octal ↔ Hex: via binary (or via decimal).

CPU & memory

CPU = ALU + CU + Registers.
ALU does arithmetic & logic; CU controls; registers (PC, IR, MAR, MDR, ACC) are fastest.
Primary: RAM (volatile) + ROM (non-volatile) + Cache.
Secondary: HDD, SSD, optical, pen drive, cloud.
Buses: data, address (n lines → 2ⁿ locations), control.

Codes

BCD (4 bits/digit, 8421) · Excess-3 (digit+3) · Gray (1-bit change) · ASCII (7/8 bits; A=65, a=97, 0=48) · EBCDIC (8-bit, IBM) · Unicode (all languages) · Parity bit (error detection).

Characteristics

Speed · Accuracy · Diligence · Versatility · Storage · Automation · Reliability · Cost-effectiveness · Logical decisions · Memory — but no intelligence, no emotions, no common sense (GIGO).

Types of computers

By data: Analog · Digital · Hybrid.
By size: Super > Mainframe > Mini > Micro.
By purpose: General-purpose · Special-purpose.
